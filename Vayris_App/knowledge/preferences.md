# Vayris Preferences

## Performance
- prioritize fast response
- avoid unnecessary model calls
- avoid unnecessary RAG retrieval
- preserve low-latency direct conversation

## Engineering
- prefer clean architecture
- prefer modularity
- prefer measurable performance
- prefer local-first implementations
- prefer deterministic logic where possible

## Product
- Vayris should feel like a capable personal AI assistant
- system actions should feel immediate
- model choice should be controllable
- tools should be reliable
- failures should be transparent
